**Deja de perder el rumbo. Empieza a conocerte de verdad.**

**TivanHab** es tu espacio personal para registrar, seguir y mejorar tus hábitos, tareas y pensamientos. Diseñado con un enfoque minimalista y funcional, te ayuda a construir una versión mejor de ti mismo, un día a la vez.

## 🌟 ¿Por qué TivanHab?

En un mundo lleno de distracciones, TivanHab te ofrece un lugar para:

- **Organizar tu día**: Captura ideas, gestiona tareas y no olvides ningún detalle importante.
- **Construir hábitos**: Registra tus rutinas diarias y observa cómo se convierten en parte de ti.
- **Conocerte a ti mismo**: Lleva un registro de tus estados de ánimo, pensamientos y progreso a lo largo del tiempo.

Es simple, es limpio, es para ti.

## 🚀 Comienza en Segundos

Es muy fácil empezar a usar TivanHab.

```bash
# 1. Clona el repositorio
git clone https://github.com/LianniSuarezAmaya/TivanHab.git

# 2. Entra al directorio
cd TivanHab

# 3. Instala las dependencias
npm install

# 4. ¡Listo! Ejecuta el servidor de desarrollo
npm run dev
```
